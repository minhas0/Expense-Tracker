Your data lives only in the phone's browser storage, so clearing site data or uninstalling the app erases all of it. [Certain] I built in a Backup button (JSON) and a Restore button, and you need to use them. Back up monthly, or this app will eventually cost you your records.
What you got: Ledger, an installable web app (PWA), not an APK. The five files (index.html, manifest.json, sw.js and two icons) go in one folder.
Day / Month / Year tabs: each shows spent, income and net for that period, with prev/next arrows.
Month and Year views: both add a category breakdown. The Year view has a bar for each month, and tapping a month or day jumps into it.
Adding entries: the + button takes an amount, expense or income, a category chip, a note and a date. Tapping any entry edits or deletes it.
Extras: CSV export, currency switch (₹ default), dark mode, and offline use after the first load.
To get it on your phone: an install icon needs HTTPS, so opening the file from your phone's storage won't work. [Likely] The easiest free route:
1: Create a GitHub repo and upload the five files.
2: Turn on GitHub Pages for it (Settings → Pages → deploy from the main branch).
3: Open the Pages URL in Chrome on your phone, then use ⋮ → "Install app" or "Add to Home screen".
